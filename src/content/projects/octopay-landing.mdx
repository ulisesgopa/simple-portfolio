## Overview

**Octopay** is a digital payment platform connecting businesses to modern financial infrastructure. The landing page needed to communicate trust, technical capability, and ease of integration, targeting both SME owners and technical decision-makers.

---

## Role
**Frontend Developer**: full implementation from design reference to production build.

---

## The Problem

A fintech product needs its landing page to do two jobs simultaneously:
1. Build trust with non-technical business owners who care about security and simplicity
2. Satisfy technical evaluators who look for integration docs, API references, and partner ecosystem

Most landing pages optimize for one audience and lose the other.

---

## Solution

A multi-section landing with distinct content layers per audience, business sections (Hero, Benefits, Testimonials) flow into technical sections (Integrations, Security, API reference, Partners) without feeling disconnected.

### Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | Next.js (App Router) |
| Animations | Framer Motion |
| UI components | shadcn/ui + Radix UI |
| Styling | TailwindCSS |
| Language | TypeScript |
| Icons | Lucide React |

### Sections Built

1. **Hero**: Primary CTA with animated entrance
2. **Services**: Core product offerings with detail pages
3. **Features**: Capability grid with icons
4. **Partners**: Logo carousel of integrations
5. **Integration**: How to connect Octopay to existing systems
6. **Security**: Trust signals, certifications, data handling
7. **Team**: Key people behind the platform
8. **News**: Latest updates with detail pages
9. **FAQ**: Accordion with categorized questions
10. **Help Center**: Support pathways
11. **Contact Methods**: Multiple contact channels
12. **Contact Form**: Validated form with Zod

---

## Final Thoughts

Octopay shows production-level landing page development: modern stack (React 19), thoughtful animations, accessible components, and a multi-audience content strategy. It goes well beyond a template, every section addresses a specific conversion goal.
