## Overview

**Octopay** is a digital payment platform connecting businesses to modern financial infrastructure. The landing page needed to communicate trust, technical capability, and ease of integration, targeting both SME owners and technical decision-makers.

---

## Role
**Frontend Developer**: full implementation from design reference to production build.

---

## The Problem

A fintech product needs its landing page to do two jobs simultaneously:
1. Build trust with non-technical business owners who care about security and simplicity
2. Satisfy technical evaluators who look for integration docs, API references, and partner ecosystem

Most landing pages optimize for one audience and lose the other.

---

## Solution

A multi-section landing with distinct content layers per audience, business sections (Hero, Benefits, Testimonials) flow into technical sections (Integrations, Security, API reference, Partners) without feeling disconnected.

### Tech Stack

_Versions reflect the current production stack._

| Layer | Technology |
|-------|-----------|
| Framework | Next.js 15.5 (App Router) + React 19.1 |
| Language | TypeScript 5.9 |
| Styling | Tailwind CSS 3.4 |
| UI components | Custom component library built with class-variance-authority, clsx, and tailwind-merge |
| Animations | Framer Motion 12 + canvas particle background |
| i18n | Custom locale-based routing (`/[locale]`) with ES / EN dictionaries and a language selector (react-country-flag) |
| Icons | Lucide React |

### Sections Built

1. **Hero**: Primary CTA with animated entrance
2. **About**: Company story and positioning
3. **Services**: Core product offerings with detail pages
4. **Features**: Capability grid with icons
5. **Partners**: Logo carousel of integrations
6. **Integration**: How to connect Octopay to existing systems
7. **Security**: Trust signals, certifications, data handling
8. **Team**: Key people behind the platform
9. **News**: Latest updates with detail pages
10. **FAQ**: Accordion with categorized questions
11. **Help Center**: Support pathways
12. **Contact Methods**: Multiple contact channels
13. **Contact Form**: Client-side validated form with localized (ES / EN) error messages

Plus an in-page chat widget and a bilingual experience driven by a custom translation layer.

---

## Final Thoughts

Octopay shows production-level landing page development: modern stack (React 19), thoughtful animations, accessible components, and a multi-audience content strategy. It goes well beyond a template, every section addresses a specific conversion goal.
