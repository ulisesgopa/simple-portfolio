## Overview

**Octopay** is a digital payment platform connecting businesses to modern financial infrastructure. The landing page needed to communicate trust, technical capability, and ease of integration — targeting both SME owners and technical decision-makers.

---

## Role
**Frontend Developer** — full implementation from design reference to production build.

---

## The Problem

A fintech product needs its landing page to do two jobs simultaneously:
1. Build trust with non-technical business owners who care about security and simplicity
2. Satisfy technical evaluators who look for integration docs, API references, and partner ecosystem

Most landing pages optimize for one audience and lose the other.

---

## Solution

A multi-section landing with distinct content layers per audience — business sections (Hero, Benefits, Testimonials) flow into technical sections (Integrations, Security, API reference, Partners) without feeling disconnected.

## Technical Decisions Worth Explaining

**Why Next.js 15 + React 19 for a landing page?**
React 19's improved server components and streaming mean above-the-fold content renders faster. Next.js App Router enables per-section lazy loading — the FAQ accordion and contact form JavaScript only loads when the user scrolls near those sections.

**Why Framer Motion over CSS animations?**
Framer Motion handles scroll-triggered entrance animations (`whileInView`) with a clean declarative API. CSS animations would require Intersection Observer setup manually. For a page with 15+ animated sections, the DX tradeoff is justified.

**Why shadcn/ui for components?**
The FAQ accordion, contact form inputs, and navigation menu need to be accessible out of the box. Radix UI primitives handle keyboard navigation, ARIA attributes, and focus management — things that are easy to get wrong building from scratch.

---

## Challenges

1. **Animation performance** — 15+ sections with Framer Motion entrance animations can cause jank on lower-end devices. Solved by using `viewport: { once: true }` so animations only run once, and `will-change: transform` hints on heavy elements.
2. **TypeScript with Framer Motion** — Typing animated component props correctly when combining Framer's `motion` variants with custom component props required careful generic usage.
3. **Consistent section spacing** — Creating a design system of spacing tokens in Tailwind config to maintain visual rhythm across 15 sections without per-section overrides.

---

## Final Thoughts

Octopay shows production-level landing page development: modern stack (React 19), thoughtful animations, accessible components, and a multi-audience content strategy. It goes well beyond a template — every section addresses a specific conversion goal.
