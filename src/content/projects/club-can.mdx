## Overview

**El Club Can** is the web presence for a premium dog training school in Buenos Aires. The brand positions itself at the high end of the market, the site needed to reflect that through visual quality, clear methodology communication, and a lead generation flow that qualifies prospects before contact.

---

## Role
**Frontend Developer**: component architecture, routing setup, animation system, lead capture form, and deployment to Vercel.

---

## The Problem

Premium service businesses live or die by first impressions. A generic template signals commodity. The client needed a site that:
- Communicated training methodology with credibility and authority
- Differentiated visually from the typical pet service aesthetic
- Captured qualified leads, not just contact form submissions, but prospects with context about their dog's situation and training goals

---

## Solution

### Tech Stack

_Versions reflect the current production stack._

| Layer | Technology |
|-------|-----------|
| Meta-framework | TanStack Start 1.167 (static prerender) |
| UI library | React 19.2 |
| Language | TypeScript 5.9 |
| Routing | TanStack Router 1.168 (file-based) |
| Bundler | Vite 7 |
| Styling | Tailwind CSS 4.2 + tailwind-merge + class-variance-authority |
| Components | Radix UI primitives (shadcn-style component library) |
| Animations | Motion 12 (`motion/react`) |
| Forms | React Hook Form 7 + Zod |
| Server state | TanStack Query 5 |
| Performance | Vercel Speed Insights |
| Deployment | Vercel (static output) |

---

## Key Sections

1. **Hero**: Cinematic entrance with Motion animations and a direct positioning statement
2. **Methodology**: Training approach explained with visual differentiation from competitors
3. **Services**: Program tiers with premium positioning and clear value per level
4. **Testimonials**: Social proof with real client outcomes
5. **Club Can Highlight**: Brand differentiator section explaining the school's philosophy
6. **Contact / Lead capture**: Qualification form collecting dog age, breed, and specific behavioral goals before routing to the trainer

---

## Final Thoughts

Premium clients don't pay just for functionality — they pay for how it makes their brand look. El Club Can pushed every frontend decision toward quality: motion that feels intentional, components built from Radix primitives with full visual control, prerendered routes served straight from the CDN.

The technical lesson is that the most popular tool isn't always the right one. TanStack Start with statically prerendered routes served from Vercel's CDN is lighter, faster, and architecturally explicit for a scope like this. The broader lesson: a site that looks premium converts premium clients. Understanding that connection between visual execution and business outcome is what separates a developer from a product partner.
