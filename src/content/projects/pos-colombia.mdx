## Overview

**POS Colombia** is a point-of-sale system designed for small and medium businesses in Colombia that need to comply with DIAN's mandatory electronic invoicing requirements. Most existing POS software is either too expensive, too complex, or not integrated with the Colombian fiscal ecosystem.

This project includes a REST API backend and a web admin dashboard, built to be deployed to production infrastructure.

---

## Role
**Solo Developer**: backend architecture, database schema, REST API, admin frontend, electronic invoicing integration, and production deployment.

---

## The Problem

Colombian SMEs face a specific challenge:
- DIAN (Colombia's tax authority) requires electronic invoicing for all registered businesses
- Most affordable POS systems either lack this integration or require expensive monthly plans
- Businesses need: product management, sales tracking, cash register sessions, and legal invoices, all in one system

---

## Solution

A self-hostable POS system with two separate parts:

### Backend, REST API

| Layer | Technology |
|-------|-----------|
| Runtime | Bun |
| Language | TypeScript |
| Database | PostgreSQL |
| ORM | Prisma with Accelerate |
| Auth | JWT (access token 15min + refresh token 7d) |
| API Docs | OpenAPI + Swagger UI at `/docs` |
| Deployment | Railway / Docker |

**API Modules:**
- `/auth`, JWT login with role-based guards (admin / cashier)
- `/products`, CRUD with category filtering
- `/categories`, Product taxonomy
- `/customers`, Customer database
- `/sales`, Create, list, and view sale details
- `/cash`, Open/close cash register sessions, session history
- `/business`, Business profile and fiscal settings
- `/billing/electronic-invoicing`, Factus integration config
- `/billing/factus/catalogs`, Sync DIAN catalogs (municipalities, measurement units, tributes, numbering ranges)

### Frontend, Admin Dashboard

| Layer | Technology |
|-------|-----------|
| Build tool | Vite |
| Framework | React + TypeScript |
| State | Zustand |
| Server state | TanStack Query |
| Forms | React Hook Form + Zod |
| Charts | Recharts |
| UI | shadcn/ui + Radix UI |
| Styling | TailwindCSS |
| Testing | Vitest |

---

## Final Thoughts

Most POS software sold in Colombia either ignores the DIAN requirement entirely or charges a monthly subscription that makes no financial sense for a small business. Building one that gets fiscal compliance right required understanding the regulatory landscape as deeply as the technical one — cataloguing DIAN municipalities, measurement units, tributes, and numbering ranges as domain knowledge, not just API calls.

POS Colombia demonstrates end-to-end product ownership with real business domain knowledge: a production-ready backend with documented API, a data-rich admin frontend with charts and role management, and an integration that solves a real market-specific problem that generic software skips.
